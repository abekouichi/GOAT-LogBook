GOAT LOGBOOK 取扱説明書
====================

アマチュア無線の交信記録（ログ）を入力・保存・検索するデスクトップアプリ（Rust + Slint 版）の取扱説明書です。Windows と Linux で使えます。
最終更新：2026年11月14日

【1. 概要】
・交信記録を1つのファイル（拡張子 .logbook）に保存します。
・コールサインを入力すると、同じ局の過去の交信（履歴）を表示します。また、総務省の無線局検索APIから常置場所と一括表示を取得し、取得した常置場所から市郡区ナンバーを調べて表示します。
・周波数・モード・出力・RST は、前回の入力から始まります。キーボードだけで、項目の移動と値の変更ができます。
・画面は3つのモードに分かれています。
・入力: 新しい交信を記録します。
・リスト: 記録を一覧で見て、検索します。
・編集: 記録を修正・削除します。
・印刷はせず、PDFファイルを作ります（「PDF出力」）。

【2. 起動と準備】
・実行ファイル（Windows は logbook.exe、Linux は logbook）を起動します。Windows ではタスクバーを除いた画面いっぱいに、Linux では最大化して開きます。
・前回開いたファイルがあれば、そのファイルの「リスト」画面から始まります。
・ファイルが無いときは、「ファイル」メニューの「ファイルを新規作成…」または「ファイルを開く…」を使ってください。

■ 置き場所（実行ファイルと同じフォルダ）
・setting.json：設定（自動で作成されます）
・shigunku_num.json：市郡区ナンバーの対応表（常置場所をキー、ナンバーを値にしたJSON）
・fonts/：PDF用のフォント（必要なときだけ。「6.4 PDF出力」を参照してください）
shigunku_num.json は、「設定」メニューの「市郡区ナンバーのファイルの選択…」で、別の場所のファイルに変更できます。

【3. 画面の見かた】

■ 3.1 メニューバー
・ファイル：ファイルを開く… ／ ファイルを新規作成… ／ ファイルを閉じる ／ PDF出力… ／（区切り）／ アプリの終了
・編集：切り取り ／ コピー ／ 貼り付け
・設定：総務省無線局検索APIを使用する／使用しない ／ 市郡区ナンバーのファイルの選択… ／ 一覧・履歴の表示項目… ／ ダークモード ／ 時計表示 ／ 時計の秒表示 ／ ポップアップ表示 ／ コールサイン入力欄 ／ 保存・キャンセルボタン
・ヘルプ：FAQ ／ 取扱説明書 ／ ライセンス（MIT）
メニューバーの中央には、「設定」で登録した自分のコールサインを「Radio Station コールサイン　GOAT LogBook」の形で表示します（未登録のときは「GOAT LogBook」）。メニューバーの右側には、現在時刻（時:分:秒）の時計を表示します。
「ヘルプ」メニューの「FAQ」「取扱説明書」「ライセンス（MIT）」は、アプリの中に画面を開いて表示します。Esc キーまたは「閉じる」ボタンで閉じます。取扱説明書の画面の文章は、アプリに内蔵したものです。
「編集」メニューは、いまカーソルがある入力欄（入力モード・編集モードの各欄とメモ欄、リストの検索欄、設定のコールサイン欄）に対して働きます。カーソルがある入力欄が無いときは、何も起きません。キーボードの Ctrl+X・Ctrl+C・Ctrl+V でも、同じ操作ができます。

■ 3.2 右上のモードボタン
・「入力」「リスト」「編集」の3つが並びます。今のモードのボタンが緑になります。
・「編集」は、押せないラベルです。記録をダブルクリックすると、編集モードに入ります。F11キーで入力モード、F12キーでリストモードにも切り替えられます（どの画面でも使えます）。
・左側には、開いているファイル名を表示します。その右の赤い文字は、状態や警告のメッセージです。

■ 3.3 画面のフォント
・標準のフォントは Noto Sans JP です。
・次の項目は、等幅フォントで表示します（Windows は Consolas、Linux は Inconsolata）。入力欄、リスト、履歴、メニューバーのコールサインと時計に共通です。
・日付、開始時刻、終了時刻、コールサイン、RST(S)、RST(R)、周波数、モード、出力、市郡区ナンバー、一括表示
・名前、QTH、常置場所、メモは、Noto Sans JP で表示します。
・PDFも、同じ組み合わせのフォントを使います（「6.4 PDF出力」を参照してください）。
・これらのフォントがパソコンに入っていないときは、画面では代わりのフォントで表示されます。

【4. 入力モード】

■ 4.1 項目
・日付：yyyy/mm/dd。欄に移ると、空なら今日の日付が入ります。
・開始時刻：HH:MM。欄に移ると、空なら現在時刻が入ります。
・コールサイン：半角の英数字と「/」だけ入力でき、小文字は大文字になります。
・RST(S)・RST(R)：数字2〜3桁です。欄に移ると、空なら開始値が入ります（「4.2 前回の値から始まる項目」を参照してください）。
・周波数：一覧から選ぶか、直接入力します。欄に移ると、空なら前回の値が入ります。
・モード：一覧から選ぶか、直接入力します。欄に移ると、空なら前回の値が入ります。
・出力：一覧から選ぶか、直接入力します。欄に移ると、空なら前回の値が入ります。
・名前・QTH：自由入力です。
・メモ：自由入力です（5行分。超えるとスクロールバーが出ます）。
・常置場所・市郡区ナンバー・一括表示：自動表示です（入力できません）。常置場所と一括表示はAPIから、市郡区ナンバーは常置場所から引きます。
・終了時刻：HH:MM。欄に移ると、空なら現在時刻が入ります。
一覧の内容
・周波数: 1.9MHz、3.5MHz、3.8MHz、7MHz、10MHz、14MHz、18MHz、21MHz、24MHz、28MHz、50MHz、144MHz、430MHz、1200MHz、2400MHz、5600MHz、10.1GHz
・モード: CW、SSB、AM、FM、FT8、RTTY、SSTV
・出力: 1W、5W、10W、50W、100W、200W、1kW

■ 4.2 前回の値から始まる項目
周波数・モード・出力・RST(S)・RST(R) は、「保存して次入力」で保存したときの値を setting.json に記録します。次に入力するときは、空の欄に移ると、その前回の値から始まります。アプリを終了しても、記録は引き継がれます。
・周波数・モード・出力: 前回保存した値がそのまま入ります。
・RST(S)・RST(R): 前回の「桁数」で開始値が決まります。RST(S) と RST(R) は、別々に記録します。
・2桁（例: 57）：59
・3桁（例: 579）：599
・前回なし：59
・RST の ↑↓ キーで、S の桁だけを変えられます（「4.4 矢印キーで値を変える」を参照してください）。
・はじめて使うときや、前回の記録がないときは、周波数・モード・出力は空のままです。

■ 4.3 入力のチェック
・日付と時刻は、間違った形になる入力を受け付けません。区切りの「/」や「:」は自動で入ります。
・例: 20261030 と入力すると 2026/10/30 になります。
・存在しない日付（2月30日など）や、24時以降の時刻は入力できません。
・RSTは、数字だけで最大3桁です。
・保存するときに、次の項目が未入力だと保存されません。日付、開始時刻、コールサイン、RST(S)、RST(R)、周波数、モード。
・保存するときに形式が正しくない項目があると、赤い文字で知らせ、保存されません。

■ 4.4 矢印キーで値を変える（↑↓）
・日付: カーソルがある位置の単位（年・月・日）が増減します。年は「yyyy」の部分、月は「mm」の部分、日は「dd」の部分です。
・時刻: カーソルが時の部分なら時が、分の部分なら分が増減します。分は、59から0に進むと時が繰り上がり、0から59に戻ると時が繰り下がります（00:00と23:59の間は循環します）。
・周波数・モード・出力: 一覧の順に切り替わります。
・RST(S)・RST(R): S の桁だけが 1〜9 の範囲で増減します。
・2桁のとき: 1の桁が変わります。↓で下がり（最小1）、↑で上がります（最大9）。例: 59 → 58 → … → 51
・3桁のとき: 10の桁が変わります。↓で下がり（最小1）、↑で上がります（最大9）。例: 599 → 589 → … → 519

■ 4.5 コールサインの確定
コールサインを入力して Enter、→、Tab のどれかを押すと、次の処理をして、次の項目（RST(S)）へ移ります。
・同じ局の過去の交信を「履歴」に表示します。
・総務省のAPIで、常置場所と一括表示を取得して表示します（設定でAPIを使う場合）。市郡区ナンバーは、取得した常置場所をもとに shigunku_num.json から引いて表示します。
・コールサインに「/」がある場合は、「/」より前の部分で検索します。常置場所と市郡区ナンバーは、（）付きで表示されます。
・該当が無いときは「Not found」と表示します。検索は、呼出符号が完全に一致する局だけを対象にします（部分一致の局は除きます）。
・取得に失敗したときは「取得エラー」と表示し、詳しい理由が赤い文字で出ます。

■ 4.6 保存とクリア
・保存して次入力: 記録をファイルに追加して、入力欄を空にします。日付欄に移ります。
・クリア: 入力した内容と履歴を消して、日付欄に移ります。
・保存は、ボタンをマウスでクリックするか、ボタンにフォーカスがある状態でEnterを押したときだけ実行します（スペースキーでは実行しません）。
・ボタンにマウスを重ねるだけで色が変わりますが、実行は押したときです。

■ 4.7 履歴
・画面の下半分に、同じ局の過去の交信を表示します。
・右のボタンの「日時昇順」「日時降順」で、並び順を切り替えます。「履歴」の右に、履歴の件数（単位：件）を表示します。履歴の右にはスクロールバーがあります。
・行にマウスを当てると、ポップアップで内容（日付・開始時刻・コールサイン、RST・周波数・モード、メモ）を確認できます。

【5. キー操作】
入力モードと編集モードで使えます。
・Enter：入力を確定して、次の項目へ移動します（メモ欄を除く）。ボタンでは実行します。
・→：Enter と同じです（メモ欄を除く）。ボタンの間では、次のボタンへ移ります。
・←：前の項目へ戻ります（メモ欄を除く）。ボタンの間では、前のボタンへ移ります。
・Tab：確定して、次の項目へ移動します。
・PgDn：Tab と同じです。
・Shift+Tab：前の項目へ戻ります。
・PgUp：Shift+Tab と同じです。
・Home：日付欄へ移動します。
・End：保存ボタンへ移動します（編集モードでは「保存して終了」）。
・↑ / ↓：日付・時刻・RST・周波数・モード・出力の値を変えます。
・F11：入力モードへ切り替えます（どの画面でも使えます）。
・F12：リストモードへ切り替えます（どの画面でも使えます）。
移動の順番
日付 → 開始時刻 → コールサイン → RST(S) → RST(R) → 周波数 → モード → 出力 → 名前 → QTH → メモ → 終了時刻 → 保存して次入力 → クリア → 日付
・メモ欄は複数行なので、Enter は改行、←→ はカーソルの移動になります。メモ欄で Tab を押すと、タブ文字は入らずに、終了時刻へ移ります。
・ほかの欄では、← → が項目の移動になるため、欄の中で文字単位にカーソルを動かすことはできません。カーソルの位置を変えたいときは、マウスでクリックしてください。Shift・Ctrl・Alt を押しながらの ← → は、ふつうのカーソル移動（範囲選択など）として働きます。
・Home・End は、これらの欄の中でも、カーソルの移動ではなく上の動作になります。

【6. リストモード（一覧）】
・「リスト」ボタンで開きます。保存したすべての記録が一覧になります。
・「日時昇順」「日時降順」で、並び順を切り替えます（選んだ方が薄い青になります。この設定は、履歴と共通で、次回の起動にも引き継がれます）。
・1行おきに背景が薄いグレーになります。リストの項目名の右に、記録の件数（単位：件）を表示します。リストの右にはスクロールバーがあり、クリックやドラッグで表示位置を動かせます。
・行にマウスを当てると、内容のポップアップが出ます。
・行をダブルクリックすると、その記録の「編集モード」に入ります。

■ 6.1 検索
・右上の検索欄に語を入力して Enter を押すと、絞り込みます。「クリア」ボタンで全表示に戻ります。検索中は、検索ボックスの右に検索結果の件数（単位：件）を表示します。
・語はスペースで区切ります。すべての語を含む記録だけが残ります（AND検索。大文字・小文字は区別しません）。
・日付の範囲は、次の形で指定できます。
・2026/10/01-：その日以降
・-2026/10/31：その日まで
・2026/10/01-2026/10/31：その期間
・編集をして一覧に戻ったときは、検索語と絞り込みが残っています。「リスト」ボタンを押して開き直すと、検索はクリアされます。

■ 6.2 列幅の変更
・見出し行の各列の右端をドラッグすると、列の幅を変えられます（一覧と履歴で共通です）。
・変更した幅は、保存されて次回の起動に引き継がれます。

■ 6.3 キーボードでの行の選択
リストモードでは、キーボードで行を選んで操作できます。選んだ行は、青く表示されます。検索欄にいるときは、Tabを押すと、一覧の操作に移ります。
・Tab / ↓：1行下へ移動します。
・Shift+Tab / ↑：1行上へ移動します。
・PgDn：12行下へ移動します。
・PgUp：12行上へ移動します。
・Home：先頭の行へ移動します。
・End：最後の行へ移動します。
・Enter：選んでいる行の「編集モード」に入ります。
・F11 / F12：入力モード／リストモードへ切り替えます。
行をクリックしても、その行を選べます。移動の途中で、選んだ行が画面の外に出ないよう、自動でスクロールします。

■ 6.4 PDF出力
「ファイル」メニューの「PDF出力…」で、PDF出力の画面を開きます。この画面では、PDFのイメージ（プレビュー）を見ながら、上・下・左・右の余白（mm）を調整できます。余白を変えると、プレビューがすぐに変わります。調整した余白は保存され、次回にも使われます。「PDF保存」ボタンを押すと、保存先を選んで、PDFファイルとして保存します。保存先の選択とPDFの作成は、画面とは別に行うので、保存している間も画面は止まりません（ボタンは「保存中…」になります）。使ったフォントは、PDFに埋め込まれます。このアプリは、紙への印刷は行いません。印刷が必要なときは、保存したPDFをPDFビューアーなどで開いて、印刷してください。
・PDFに入れる項目（列）は、「設定」メニューの「一覧・履歴の表示項目…」で選んだ項目に従います。
・PDFにする行は、画面のリストと同じです。検索で絞り込んでいるときは、絞り込んだ結果だけをPDFにします。並び順（日時昇順・日時降順）も、画面と同じです。
・見出しには、ファイル名、自分のコールサイン（登録している場合）、出力日時、件数、検索語（検索中の場合）を載せます。
・プレビューは、A4横向きの用紙のイメージで表示します。「前のページ」「次のページ」ボタン、または PgUp・PgDn・矢印キーでページを移り、「閉じる」ボタンまたは Esc キーで閉じます。
・PDFの表の列幅は、内容に合わせて決めます。列の見出しは、文字が途切れないよう、見出しの幅より狭くしません。用紙に収まらないときは、見出しより広い分だけを縮めます。見出しだけでも収まらないときは、見出しの文字を小さくします。メモは、1行に収めます。ページ番号は、各ページの下に載せます。
・ファイルを開いていないとき、またはPDFにするデータがないときは、赤い文字で知らせます。
PDFのフォント
画面と同じ組み合わせです。本文・見出しは Noto Sans JP（無ければ Noto Sans CJK JP）、日付・時刻・コールサイン・RST・周波数・モード・出力・市郡区ナンバー・一括表示は、Windows は Consolas、Linux は Inconsolata です。名前・QTH・常置場所・メモは Noto Sans JP です。等幅フォントに無い文字（日本語など）を含む欄は、その欄だけ Noto Sans JP で描きます。
フォントは、次の順に探します。
・setting.json の font_regular・font_bold・font_mono で指定したファイル（最優先）
・実行ファイルと同じ場所の fonts フォルダ
・システムのフォントフォルダ（Windows: Windows\Fonts とユーザーのフォント、Linux: /usr/share/fonts、~/.local/share/fonts など。サブフォルダも探します）
・本文（必須）：NotoSansJP-Regular.ttf（可変フォントの NotoSansJP-VariableFont_wght.ttf、NotoSansCJK-Regular.ttc なども可）
・見出し（任意）：NotoSansJP-Bold.ttf（無ければ本文と同じ字体）
・等幅（任意）：Windows: consola.ttf、Linux: Inconsolata-Regular.ttf など（無ければ本文と同じ字体）
・PDFには、TrueType 形式（.ttf）のフォントをおすすめします。Noto Sans CJK の .ttc / .otf や、Debian系の Inconsolata.otf（CFF形式）は、PDFビューアーによって文字が出ないことがあります。
・本文のフォントが見つからないときは、赤い文字で知らせます。そのとき、探した場所も表示します。

【7. 編集モード】
入力モードと同じ画面で、選んだ記録の内容を修正します。下のボタンは次のとおりです。
・保存して終了：修正を保存して、一覧に戻ります。
・元に戻す：入力欄を、編集を始めたときの内容に戻します（編集は続きます）。
・保存せず終了：修正を捨てて、一覧に戻ります。
・削除：この記録を削除して、一覧に戻ります。確認の画面は出ません。
・編集中は、「入力」「リスト」ボタンを押しても移動できません。赤い文字で警告が出ます。上の4つのボタンのどれかで終了してください。
・入力モードと同じく、必須項目と形式のチェックがあります。キー操作も、入力モードと同じです。

【8. モードの切り替え】
・入力中の内容（コールサイン・RST・名前・QTH・メモのどれか）があるときは、「リスト」を押しても移動できず、警告が出ます。「保存して次入力」するか「クリア」してください。
・RSTは、欄に移ると開始値が自動で入ります。開始値のままなら、入力中の内容には数えません（値を変えたときだけ、入力中になります）。
・内容がないときに「リスト」を押すと、入力欄を空にして一覧に移ります。

【9. 設定】
・総務省無線局検索APIを使用する／しない：「しない」にすると、常置場所・市郡区ナンバー・一括表示の欄は灰色になり、取得も表示もしません。
・市郡区ナンバーのファイルの選択…：対応表（JSON）の場所を変更します。
・一覧・履歴の表示項目…：一覧と履歴に表示する項目（日付・開始時刻・終了時刻・コールサイン・RST(S)・RST(R)・周波数・モード・出力・名前・QTH・常置場所・市郡区ナンバー・一括表示・メモ）を、チェックで選びます。選択は一覧と履歴で共通で、次回の起動にも引き継がれます。項目を選んでもメニューは開いたままで、メニューの外側をクリックすると閉じます。
・ダークモード：画面を暗い配色にします（チェックを付けると有効）。
・コールサイン：自分のコールサインを入力します。メニューバーの中央に表示されます。
「時計表示」にチェックを付けると、メニューバー右側の時計を表示し、外すと非表示にします。「時計の秒表示」にチェックを付けると、時計に秒まで表示します。「ポップアップ表示」にチェックを付けると、リストと履歴の行にマウスを当てたときのポップアップを表示し、外すと表示しません。設定メニューで変えた内容は、「保存」ボタンを押したときに反映され、保存されます。「キャンセル」ボタンを押す（またはメニューの外側をクリックする）と、変更は捨てられます。どちらのボタンを押しても、設定メニューは閉じます。

【10. データと設定ファイル】

■ 10.1 ログファイル（.logbook）
・形式はJSONで、1件の記録が1つのオブジェクトです。項目名がキーになっています。
・項目名は、次のとおりです。日付、開始時刻、終了時刻、コールサイン、RST(S)、RST(R)、周波数、モード、出力、名前、QTH、メモ、常置場所、市郡区ナンバー、一括表示。
・保存のたびに、ファイル全体を書き直します（一時ファイルを作ってから置き換えるので、途中で失敗しても元のファイルは壊れません）。
・バックアップは、.logbook ファイルをコピーするだけで取れます。定期的にコピーすることをおすすめします。

■ 10.2 setting.json の項目
・last_file：最後に開いたファイル
・use_api：APIを使うか
・sort_asc：日時昇順にするか
・cols：列幅（14個の数値）
・cols_ver：列幅の内部バージョン（変更しないでください）
・col_show：一覧・履歴に表示する項目（15個の真偽値）
・dark：ダークモード
・my_call：自分のコールサイン
・show_clock：メニューバー右側の時計を表示するか
・show_seconds：時計に秒まで表示するか
・show_popup：ポップアップを表示するか
・margins：PDFの余白（上・下・左・右、単位mm）
・last：前回の入力（周波数・モード・出力・RST(S)・RST(R) の5つ）。保存のたびに更新されます
・font_regular：PDFの本文のフォントファイルの場所（省略すると、上の順に探します）
・font_bold：PDFの見出し（太字）のフォントファイルの場所
・font_mono：PDFの等幅のフォントファイルの場所
・num_file：市郡区ナンバーのファイルの場所
・api_url：検索APIのURL（{callsign} の部分が呼出符号に置き換わります）

【11. 困ったときは】
・「ファイルを開くか新規作成してください」と出て保存できない：「ファイル」メニューから、ファイルを開くか新規作成します。
・「未入力: …」と出る：必須項目（日付・開始時刻・コールサイン・RST(S)・RST(R)・周波数・モード）を入力します。
・「形式が正しくありません: …」と出る：日付は yyyy/mm/dd、時刻は HH:MM、RSTは2〜3桁の数字にします。
・常置場所が「取得エラー」になる：赤い文字の理由を確認します。インターネットに接続できているか、api_url が正しいかを確認してください。
・常置場所が「Not found」になる：該当の局が無いか、shigunku_num.json に、その常置場所の対応が無い可能性があります。
・「入力中の内容があります」と出る：「保存して次入力」するか「クリア」します。
・「編集中は他のモードに移れません」と出る：「保存して終了」「元に戻す」「保存せず終了」「削除」のどれかで編集を終えます。
・PDFで「Noto Sans JP が見つかりません」と出る：実行ファイルと同じ場所の fonts フォルダに NotoSansJP-Regular.ttf を置きます。または、font_regular で場所を指定します。赤い文字に、探した場所が出ます。
・PDFを開くと文字が出ない、または一部の文字が欠ける：CFF形式（.otf、.ttc）のフォントを使っている可能性があります。TrueType 形式（.ttf）のフォントを fonts フォルダに置いてください。
・コールサインなどが等幅で表示されない：Windows は Consolas、Linux は Inconsolata が入っているか確認します。無いときは、代わりのフォントで表示されます。
・ダークモードでタイトルバーだけ明るい：タイトルバーは、お使いのOSの設定に従います。

【12. 注意事項】
・「削除」は、確認なしで実行されます。ご注意ください。
・入力欄では、← → が項目の移動になります。欄の中のカーソルは、マウスで動かしてください（メモ欄は除く）。
・周波数・モード・出力・RSTの前回値は、保存のたびに setting.json に記録されます。setting.json を消すと、前回値も消えます。
・履歴の行は、履歴の画面からは編集できません。編集は、「リスト」画面の行をダブルクリックして行います。

【付録: ビルドと起動（開発者向け）】
・Rust をインストールします（Windows は MSVC ツールチェーン）。
・プロジェクトのフォルダで cargo run --release を実行します。初回は、依存クレートの取得にネットワークが必要です。
・作成された実行ファイルは target/release/logbook（Windows は logbook.exe）です。setting.json と shigunku_num.json、必要なら fonts フォルダは、この実行ファイルと同じフォルダに置きます。
